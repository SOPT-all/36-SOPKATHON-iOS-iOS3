> 정해진 만큼 걸을 때마다 섬을 정복하고 전라남도 섬 관련 설명 엽서를 얻음으로써, 전라남도 섬에 대한 사람들의 인지도와 친밀도를 높일 수 있도록 돕는 서비스

## 브랜치 전략

### 📌 브랜치 구조

```swift
develop         ← 통합 개발 브랜치
│
└─ feat/#이슈번호   ← 기능 단위 개발 브랜치
```

### 🛠 깃 플로우 요약

**이슈 파고**

→ 이슈명: [type]: 작업할 내용(이슈)

→ ex: [setting]: 네트워크 세팅

**브랜치 파고**

→ 브랜치명: type/#이슈번호

→ ex: setting/#4

**작업 끝나면 pr 올리고**

→ pr 제목: [type] 작업한 내용

→ ex: **[setting] 네트워크 세팅**

### 🧑‍💻 커밋 메시지 규칙

- 커밋 메세지 형식: [type] 작업한 내용

| 태그 | 설명 |
| --- | --- |
| `feat` | 새로운 기능 |
| `fix` | 버그 수정 |
| `refactor` | 코드 리팩토링 (기능 변화 없음) |
| `docs` | 문서 변경 |
| `style` | 코드 포맷팅, 세미콜론 누락 등 |
| `test` | 테스트 코드 추가 |
| `chore` | 기타 변경사항 (빌드, 설정 등) |
